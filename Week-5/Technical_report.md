# WEEK 5 – INTERNSHIP TASK REPORT

## Project Title: FocusFlow – Personal Productivity Dashboard

### 1. Objective
The objective of this task was to simulate a Single Page Application (SPA) using HTML, CSS and JavaScript. The application dynamically displays different content without requiring a complete page reload.

### 2. Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Live Server

### 3. Project Implementation

**HTML:** Created the main application structure, including the sidebar navigation and the main content area.

**CSS:** Designed a consistent dashboard interface with responsive layouts, styling, and visual transitions.

**JavaScript:** Implemented client-side navigation and dynamic content rendering. Navigation updates the URL using hash-based routing, allowing different application views to be displayed without reloading the entire page.

### 4. Key Features
- Dashboard interface with sidebar navigation.
- Dynamic content rendering.
- Client-side navigation using URL hash changes.
- Browser navigation support through URL history.
- Consistent styling across application views.
- Interactive navigation between application sections.

### 5. Challenges Faced

During development, the JavaScript file initially failed to load because the file path was incorrect. This caused the application to remain on its loading message.

The issue was resolved by ensuring that the JavaScript file was placed inside the Week-5 folder and that the script reference pointed to the correct file.

### 6. Testing

The application was tested using Live Server in the browser.

The following aspects were checked:
- Application loading.
- Navigation between available sections.
- URL changes during navigation.
- Dynamic content display without a full-page refresh.
- Browser navigation behaviour.

### 7. Conclusion

This task provided practical experience in developing a Single Page Application simulation. It improved my understanding of JavaScript-based routing, DOM manipulation, browser history, and dynamic content management.

The FocusFlow project demonstrates how HTML, CSS, and JavaScript can work together to create an interactive web application.
