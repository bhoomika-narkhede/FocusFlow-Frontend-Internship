# FocusFlow – Personal Productivity Dashboard

A responsive and interactive productivity dashboard developed as part of a 5-week Frontend Development Internship.

FocusFlow helps users organize their daily activities, manage tasks, track goals, and monitor their productivity through a clean and user-friendly interface.

## Project Overview

This project was developed progressively over five weeks, with each week focusing on a different aspect of frontend development, from basic HTML and CSS to JavaScript interactions, responsive design, accessibility, and Single Page Application (SPA) simulation.

## Technologies Used

- **HTML5** – Webpage structure and semantic elements
- **CSS3** – Styling, responsive layouts, transitions, and animations
- **JavaScript** – Dynamic content, DOM manipulation, event handling, and client-side routing
- **Local Storage** – Persistent storage of user data
- **Git & GitHub** – Version control and project management
- **Visual Studio Code** – Development environment

## Features

- Responsive productivity dashboard
- Task creation, completion, deletion, and search
- Dynamic task statistics and progress tracking
- Goal management
- Calendar section
- Profile customization
- Local Storage data persistence
- Client-side navigation using URL hash routing
- Browser Back and Forward navigation
- Accessible interface with semantic HTML and ARIA attributes
- CSS transitions and animations

## Weekly Development

| Week | Focus Area | Work Completed |
|---|---|---|
| Week 1 | Static Dashboard | Created the basic dashboard layout using HTML and CSS. |
| Week 2 | Responsive Design | Adapted the dashboard for desktop, tablet, and mobile screens. |
| Week 3 | JavaScript Interactions | Added task management, search, dynamic statistics, and Local Storage. |
| Week 4 | Performance & Accessibility | Improved semantic structure, accessibility, and overall performance. |
| Week 5 | SPA Simulation | Implemented dynamic page rendering, client-side routing, and browser history navigation. |

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the `Week-5` folder.
4. Open `index.html` using the Live Server extension or a web browser.
5. Explore the dashboard and navigate between its sections.
